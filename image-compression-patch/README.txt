ПАЧ: компресия на седемте изображения от PageSpeed

1. Качете apply_image_compression.py в папката на магазина до app.py
   и responsive_images.py. Не е нужно да заменяте шаблони.
2. В cPanel Terminal активирайте Python средата на магазина с командата,
   показана в Setup Python App, и влезте в папката на приложението.
3. Изпълнете:
   python apply_image_compression.py
4. При съобщение OK рестартирайте приложението от Setup Python App.
5. Пуснете нов PageSpeed анализ.

Пачът сменя качеството от 82 на 65 за варианти до 320 px и на 72
за по-големите. Генерира отново само седемте посочени изображения.
Новите качвания също ще използват новата компресия.
Имената на вариантите получават нов хеш, за да се обнови браузърният кеш.
Оригиналите, базата данни, логото и шаблоните не се променят.
Старите WebP файлове остават налични за вече отворени страници.

Създава image-compression-backup-ДАТА с предишния responsive_images.py
и предишните JSON манифести. За връщане: възстановете Python файла
в корена на приложението, JSON файловете в static/img/products/_responsive/
и рестартирайте приложението. Новите WebP могат да останат неизползвани.
При непознат код или липсващи оригинали пачът спира без промени.
При грешка в генерирането възстановява предишните манифести и Python файл.

57 KiB е оценка на PageSpeed, а не гарантирана икономия от този пач.
