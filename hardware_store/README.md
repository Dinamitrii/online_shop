# Железария Ковач — онлайн магазин (Flask)

Прост, но пълнофункционален онлайн магазин за железария, изграден с Flask и SQLite.

## Функционалности

- Категории продукти (инструменти, електроинструменти, крепежни елементи, боя, ключалки, градина)
- Начална страница с категории и нови продукти
- Страница за категория с търсене
- Търсене по цялото сайт
- Детайлна страница на продукт
- Количка за пазаруване (пази се в session)
- Поръчка (checkout) с формуляр за клиентски данни
- Потвърждение на поръчка
- SQLite база данни, автоматично създадена с примерни продукти

## Инсталация

```bash
cd hardware_store
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Стартиране

```bash
python app.py
```

При първо стартиране автоматично се създава `store.db` и се зареждат примерни продукти
(ако базата е празна). Приложението ще е достъпно на `http://127.0.0.1:5000`.

Алтернативно, можеш изрично да инициализираш базата:

```bash
flask --app app.py init-db
```

## Структура на проекта

```
hardware_store/
├── app.py                 # Flask рутове и логика
├── models.py               # SQLAlchemy модели (Category, Product, Order, OrderItem)
├── requirements.txt
├── static/
│   └── css/style.css       # Стилове
└── templates/
    ├── base.html            # Основен layout (навигация, футър)
    ├── index.html           # Начална страница
    ├── category.html        # Продукти в категория
    ├── search.html          # Резултати от търсене
    ├── product.html         # Детайли за продукт
    ├── cart.html             # Количка
    ├── checkout.html         # Формуляр за поръчка
    └── confirmation.html     # Потвърждение на поръчка
```
