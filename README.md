# Железария Ковач — онлайн магазин (Flask)

Прост, но пълнофункционален онлайн магазин за железария, изграден с Flask и SQLite.

## Функционалности

- Категории продукти (инструменти, електроинструменти, крепежни елементи, боя, ключалки, градина)
- Начална страница с категории и нови продукти
- Страница за категория с търсене
- Търсене по цялото сайт
- Детайлна страница на продукт
- Количка за пазаруване (пази се в session)
- Поръчка (checkout) с формуляр за клиентски данни
- Потвърждение на поръчка
- SQLite база данни, автоматично създадена с примерни продукти
- **Админ панел** (защитен с парола):
  - Табло с бройки продукти, поръчки и продукти с ниска наличност
  - CRUD за продукти (добавяне, редакция, изтриване)
  - Управление на категории (добавяне, изтриване ако е празна)
  - Преглед на всички постъпили поръчки с детайли

## Достъп до админ панела

Адрес: `http://127.0.0.1:5000/admin` (линк има и във футъра на сайта)

Парола по подразбиране: **`admin123`**

⚠️ Задължително я сменете преди да пуснете сайта онлайн — през environment променлива:

```bash
export ADMIN_PASSWORD="силна-парола-тук"
python app.py
```

## Инсталация

```bash
cd hardware_store
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Стартиране

```bash
python app.py
```

При първо стартиране автоматично се създава `store.db` и се зареждат примерни продукти
(ако базата е празна). Приложението ще е достъпно на `http://127.0.0.1:5000`.

Алтернативно, можеш изрично да инициализираш базата:

```bash
flask --app app.py init-db
```

## Структура на проекта

```
hardware_store/
├── app.py                 # Flask рутове и логика
├── models.py               # SQLAlchemy модели (Category, Product, Order, OrderItem)
├── requirements.txt
├── static/
│   └── css/
│       ├── style.css        # Стилове за магазина
│       └── admin.css        # Стилове за админ панела
└── templates/
    ├── base.html            # Основен layout (навигация, футър)
    ├── index.html           # Начална страница
    ├── category.html        # Продукти в категория
    ├── search.html          # Резултати от търсене
    ├── product.html         # Детайли за продукт
    ├── cart.html             # Количка
    ├── checkout.html         # Формуляр за поръчка
    ├── confirmation.html     # Потвърждение на поръчка
    └── admin/
        ├── base.html          # Layout на админ панела
        ├── login.html         # Вход в админ панела
        ├── dashboard.html     # Табло с продукти и статистика
        ├── product_form.html # Форма за нов/редактиран продукт
        ├── categories.html    # Управление на категории
        ├── orders.html        # Списък с поръчки
        └── order_detail.html  # Детайли за поръчка
```

## Следващи стъпки (идеи за разширение)

- Логин система за клиенти (Flask-Login) и история на поръчки
- Качване на файлове (снимки) вместо въвеждане на URL, чрез Flask-Uploads
- Множество администраторски акаунти с потребителско име + парола (в момента е само с обща парола)
- Качване на реални снимки на продукти (в момента се ползва emoji placeholder)
- Плащане онлайн (Stripe / EasyPay / ePay)
- Пагинация при много продукти в категория
- Deploy на production сървър (Gunicorn + Nginx, или PythonAnywhere/Render)
